# User Stories

## Doctor
- As a Doctor, I want to view my daily schedule of appointments so that I can prepare for patient visits.
- As a Doctor, I want to update the status of patient appointments so that the system reflects current clinic operations.

## Patient
- As a Patient, I want to view my scheduled appointments so that I know when my visits take place.
- As a Patient, I want to provide my contact details so that the clinic can reach me regarding updates.

## Admin
- As an Admin, I want to manage doctors and patient records so that clinic operations run smoothly.
- As an Admin, I want to generate daily appointment reports by doctor so that daily attendance and scheduling can be monitored.
